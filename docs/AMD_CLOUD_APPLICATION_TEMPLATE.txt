PROJECT NAME:
CrashLens - AI-Powered ML Failure Diagnosis Platform for AMD GPUs

PROJECT DESCRIPTION:
I'm building CrashLens, an AI-powered reliability platform that helps developers diagnose and fix failures in ML workloads running on AMD GPUs.

The platform provides:
- Real-time observability for GPU workloads and AI agents
- Automatic failure classification (GPU OOM, dependency errors, timeouts, ROCm errors)
- AI-powered root cause analysis using Gemma 2
- Actionable recommendations for fixing AMD/ROCm-specific issues
- Cost tracking (wasted GPU-seconds per failure)

I developed this project for the AMD Developer Hackathon and built it specifically for AMD ROCm GPU infrastructure. The platform is already deployed and functional with simulated workloads, but I need access to real AMD Instinct GPUs to:

1. Test against actual ROCm error messages and HIP failures
2. Capture authentic AMD GPU metrics (memory usage, temperature, utilization)
3. Build ROCm-specific failure classifiers
4. Create documentation and case studies for AMD developers
5. Validate AI diagnosis recommendations on real AMD hardware
